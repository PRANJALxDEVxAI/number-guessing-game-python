# Number Guessing Game

A command-line number guessing game developed in Python where the player attempts to guess a randomly generated number within a limited number of attempts.

## Features

- Random number generation
- User input validation
- Hint system (Higher/Lower)
- Attempt counter
- Win and lose conditions
- Simple command-line interface

## Technologies Used

- Python 3
- random module

## Installation

```bash
git clone https://github.com/PRANJALxDEVxAI/number-guessing-game-python.git
cd number-guessing-game-python
```

## Usage

```bash
python main.py
```
